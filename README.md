## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program checks the bundled image (PNG, 1024×1024, under 1 MiB) and copies it to the output directory as `entry.png`. It needs no network and writes identical bytes on every run.
